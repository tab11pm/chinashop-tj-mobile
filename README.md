# ChinaShop TJ

Официальная страница скачивания Android-приложения ChinaShop TJ.

## Скачать

Последняя версия доступна в разделе [Releases](https://github.com/tab11pm/chinashop-tj-mobile/releases/latest).

Скачайте APK, разрешите установку из этого источника в настройках Android и откройте файл.

## Оформление заказа

В розничном оформлении заказа адрес доставки не требуется: после создания заказа пункт выдачи назначит команда ChinaShop TJ. Затем можно сразу перейти к оплате.

## Обновления

Новая версия устанавливается поверх предыдущей. Если установка не начинается, скачайте APK ещё раз и проверьте свободное место на устройстве.

Исходный код мобильного приложения доступен в этом репозитории.
